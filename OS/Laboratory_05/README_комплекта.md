# Лабораторная работа 5

Основной документ — `Отчет_ЛР5.docx`. Порядок выполнения, команды и требования к каждому из 37 снимков — `Инструкция_ЛР5.md`.

Комплект на полный накопительный уровень 9–10:

- `native/Lab-05a.cpp`, `Lab-05x.cpp`, `Lab-05b.cpp`, `Lab-05c.cpp` — точки входа C++;
- `native/native.hpp` — общая реализация, Windows API и Linux разделены условной компиляцией;
- `native/bin/*.exe` — готовые x64 Windows-программы со статическим CRT;
- `native/build-windows.cmd`, `native/build-linux.sh` — повторная сборка;
- `simulation/Lab-05SJF.py`, `Lab-05RR.py`, `Lab-05CP.py`, `Lab-05MQ.py` — модели;
- `simulation/tasks.csv` — десять задач из условия;
- `simulation/scheduler.py`, `test_scheduler.py` — реализация и тесты;
- `simulation/results` — воспроизводимые контрольные модельные результаты, не измерения VM.

Исходное задание и отчёт ЛР3 не изменены. Каталог `.work` содержит только сборочные и визуальные проверки; он не предназначен для сдачи и не включён в архив переноса.

Windows-сборка проверена MSVC x64, Linux-сборка — GCC 14 в отдельном контейнере. Короткие функциональные тесты не заменяют обязательные запуски в виртуальных машинах. В отчёте оставлены места для фактических PID/TID, времени и разности итераций.

Отчёт оформлен по требованиям: А4, Times New Roman 14, одинарный интервал, поля 30/15/20/20 мм. Числа в модельных разделах относятся к указанным правилам и seed=525. После вставки снимков обновите содержание и повторно проверьте пагинацию.
