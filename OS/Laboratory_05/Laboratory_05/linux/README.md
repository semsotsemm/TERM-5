# ЛР5 — Linux

Здесь восемь консольных проектов C++17. Для непосредственного запуска в Ubuntu скопируй всю папку `linux`, открой в ней терминал и собери:

```bash
sudo apt update
sudo apt install build-essential gdb cmake
bash build.sh
./bin/Lab-05a
./bin/Lab-05x 10000 1
```

Комплект также содержит `Laboratory_05.slnx` с Linux-проектами для Visual Studio. Для их сборки и отладки из Windows нужны компонент «Разработка Linux и внедрённых приложений на C++» и подключение к Linux по SSH; для WSL выбирается соответствующий набор инструментов в свойствах проекта. Это Linux-приложения, поэтому обычная локальная Windows-отладка для них не используется. Настройка описана в [документации Microsoft](https://learn.microsoft.com/en-us/cpp/linux/configure-a-linux-project). Виртуальную машину можно использовать как целевой Linux-компьютер.

Если используешь SSH к Ubuntu, установи `openssh-server rsync zip`, запусти `sudo systemctl enable --now ssh`, добавь соединение в Visual Studio в разделе «Кроссплатформенные подключения». Выбери проект запускаемым, укажи аргументы в его свойствах отладки. Для SJF/RR/CP используется `tasks.csv`; в Linux-проектах настроено копирование входных данных и общих заголовков на целевой компьютер. Общий каталог исполняемых файлов обеспечивает запуск Lab-05x из Lab-05b.

В выводе `Lab-05a` найди `MASK_DEC` и `ONE_CPU_MASK_DEC`. Ниже для примера использованы 255 и 1 — подставь доступные значения своей системы. Для отрицательного nice нужны права, поэтому соответствующие опыты выполняются через sudo.

```bash
./bin/Lab-05b 255 0 0 1000000 200
sudo ./bin/Lab-05b 255 19 -20 1000000 200
sudo ./bin/Lab-05b 1 19 -20 1000000 200
./bin/Lab-05c 255 0 0 1000000 200
sudo ./bin/Lab-05c 255 19 -20 1000000 200
sudo ./bin/Lab-05c 1 19 -20 1000000 200
```

Полная нагрузка занимает около 200 секунд. Для быстрой проверки замени последние два аргумента на `10000 1`. В процессе работы проверяй `ps -L -p PID -o pid,tid,ni,psr,stat,comm` и `/proc/PID/task/TID/status`. `FIRST_FINISH` содержит сохранённый прогресс при первом завершении; PID и TID каждый раз новые. В Linux для Lab-05c передаются маска и два nice, дополнительного класса процесса, как в Windows, нет.

```bash
./bin/Lab-05SJF
./bin/Lab-05RR --quantum 80
./bin/Lab-05CP --quantum 80
./bin/Lab-05RR --compare
./bin/Lab-05MQ --seed 525
./bin/Lab-05MQ --seed 525 --summary
```

Для исходных десяти задач среднее ожидание: SJF=154, RR(80)=207,5, CP(80)=170,5. Перебор даёт лучший квант 80 для RR и CP по минимуму среднего ожидания среди проверенных значений. Для MQ seed=525 ожидаются 100 завершённых процессов, 397 перемещений, 2047 переключений, makespan=28957, avg_waiting=17911,13. Полные таблицы 100 процессов для каждой очереди печатаются по умолчанию; `--summary` оставляет в консоли сводку. CSV и JSON сохраняются в `results`; можно указать другой каталог через `--out`. Старые результаты оставлены в `reference-results`.

Альтернатива build.sh:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/bin/Lab-05a
```
