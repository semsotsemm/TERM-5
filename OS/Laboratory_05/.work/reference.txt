Процесс — это динамический экземпляр выполняемой программы. При запуске исполняемого файла операционная система выделяет новому процессу уникальный идентификатор (PID), изолированное виртуальное адресное пространство, процессорное время и другие системные ресурсы. Архитектура операционных систем поддерживает иерархию процессов, позволяя родительскому процессу создавать дочерние и приостанавливать свое выполнение до их завершения. В ОС Windows для инициализации дочернего процесса применяется функция CreateProcessA. В ОС Linux процесс создания разделен: системный вызов fork дублирует текущий процесс, после чего дочерний процесс замещает свой контекст новой программой с помощью вызова execl. 1.2 Системные интерфейсы Windows и LinuxВ рамках выполнения лабораторной работы используются системные функции и вызовы, перечень которых приведен в таблице 1.1. Таблица 1.1 – Средства работы с процессамиЭлементНазначение и ожидаемый результатCreateProcessAСоздаёт процесс Windows и возвращает PID и дескрипторы.WaitForMultipleObjectsОжидает завершения нескольких детей.CreateToolhelp32SnapshotСоздаёт снимок процессов для обхода записей.forkСоздаёт дочерний процесс с новым PID.execlЗагружает другую программу в дочерний процесс.waitpidОжидает выбранный дочерний процесс.pipeСоздаёт канал с концами чтения и записи.signalНазначает обработчик или игнорирование сигнала.В обеих операционных системах реализована базовая синхронизация завершения работы: родительский процесс приостанавливает свое выполнение до успешного завершения всех созданных им дочерних процессов.
