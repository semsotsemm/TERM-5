Уровень 9-10:
Приложение Lab-05MQ:
Приложение эмулирует работу планировщика с алгоритмом Multilevel Feedback Queue.
Необходимо создать эмулятор планировщика, который будет:
Разделять процессы по разным очередям в зависимости от их потребностей в CPU;
Перемещать процессы между очередями;
Отдавать приоритет процессам, которые быстро используют CPU;
Учитывать процессы с большим количеством операций ввода-вывода.
Предусмотреть как минимум три очереди:
Высокоприоритетная очередь (Q0 – потребляет 50% процессорного времени):
Предназначена для интерактивных задач;
Короткий квант времени (10-20 мс);
Алгоритм планирования: Round Robin;
Задачи попадают сюда при создании;
Если задача не использует весь квант – остается здесь.
Средняя приоритетная очередь (Q1 - потребляет 30% процессорного времени):
Для задач со средней интенсивностью CPU;
Увеличенный квант времени (40-80 мс);
Алгоритм: Round Robin;
Задача понижается сюда, если исчерпала квант в Q0;
Может повышаться обратно при I/O операциях.
Низкоприоритетная очередь (Q2 - потребляет 20% процессорного времени):
Для CPU-интенсивных задач;
Большой квант времени (100-200 мс);
Алгоритм: FCFS;
Задача попадает сюда, если исчерпала кванты в предыдущих очередях;
С равными шансами процесс может переместиться в одну из предыдущих очередей или остаться в этой, если исчерпал квант в этой очереди.
Исходные данные:
Количество процессов: 100;
Время выполнения процессов: случайное;
Типы процессов: CPU-bound и I/O-bound.
Обязательные компоненты программы
Структура процесса: ID процесса, время поступления, время выполнения, текущая очередь, время ожидания и т.д. (можно добавлять всё что требуется для работы вашей реализации)
Статистика для сбора: среднее время ожидания, общее время выполнения, количество переключений, процент использования CPU, количество перемещений между очередями.
После успешного планирования всех процессов (т.е. когда они все завершат своё выполнение), для каждой реализованной очереди планирования программа должна выводить следующую информацию по всем процессам:
Идентификатор процесса (PID);
Время поступления процесса в систему;
Время выполнения;
Время ожидания;
Оборотное время;
Статистические показатели.
Для каждого очереди необходимо рассчитать и вывести:
Среднее время ожидания (Average Waiting Time);
Среднее оборотное время (Average Turnaround Time).
