# Лабораторная работа 11 DLL

Решение `Laboratory_03.slnx` содержит DLL `OS11_HTAPI` и пять консольных проектов. Для сборки открой решение в Visual Studio, выбери **Release | x64**, затем **Сборка → Собрать решение**. Все программы и DLL появятся в `x64\Release`.

## Проверка из CMD

Открой **пять окон CMD**. В каждом перейди в папку со сборкой:

```cmd
cd /d D:\WorkSpace\TERM-5\SP\Laboratory_03\x64\Release
```

В первом окне создай файл и запусти хранилище:

```cmd
OS11_CREATE.exe demo.ht 3 2000 4 4
OS11_START.exe demo.ht
```

Параметры после имени файла идут в порядке: интервал сохранения в секундах, ёмкость, максимальная длина ключа и максимальная длина данных в байтах. `OS11_CREATE` создаёт новый файл. Для повторной демонстрации можно запустить `OS11_START.exe demo.ht` на том же файле или создать отдельное хранилище с другим именем.

Когда в первом окне появится `HT-Storage Start`, запусти по одной утилите в трёх других окнах:

```cmd
OS11_02.exe demo.ht
```

```cmd
OS11_03.exe demo.ht
```

```cmd
OS11_04.exe demo.ht
```

Утилиты выбирают ключи от 0 до 49 раз в секунду. `OS11_02` добавляет значение `0`, `OS11_03` удаляет найденную запись, `OS11_04` увеличивает найденное 32-битное значение на единицу. Смотри протоколы в окнах утилит. Сообщения «Ключ не найден» и «Ключ уже существует» показывают результат очередной попытки с выбранным ключом.

В окне `OS11_START` каждые три секунды появляется сообщение о сохранении. Нажми любую обычную клавишу в этом окне и увидишь сообщение о финальном сохранении. Работающие утилиты сообщат об отключении, а в пятом CMD можно сразу проверить отказ нового подключения:

```cmd
OS11_02.exe demo.ht
```

Чтобы остановить отдельную утилиту до закрытия хранилища, нажми **Ctrl+C** в её окне. Чтобы проверить сохранение, снова выполни `OS11_START.exe demo.ht` и подключи утилиты к тому же файлу.

## Что происходит в коде

`OS11_CREATE` создаёт файл и размечает ячейки. `OS11_START` открывает файл и создаёт именованный File Mapping. Остальные процессы присоединяются через `HT::Open` и используют DLL через библиотеку импорта. Межпроцессный mutex защищает поиск, изменение ячеек и сохранение. Чтение и увеличение числа в `HT::Increment` выполняются под одной блокировкой.

`HT::Close` в `OS11_START` прекращает доступ и сохраняет файл через `FlushViewOfFile` и `FlushFileBuffers`. В заголовке файла лежат параметры и номер запуска. Указатели, строки ошибок и Win32-дескрипторы находятся в памяти отдельных процессов. Для этой лабораторной создай файл через `OS11_CREATE`, у формата есть собственный заголовок.
