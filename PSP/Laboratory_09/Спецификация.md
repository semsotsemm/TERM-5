
1) Обнаружение UDP-сервера: отправляется широковещательный запрос на порт 2000, с позывным FindServer. В ответ приходит строка, с приветствующим текстом  и указанием TCP порта `"Welcome to ConcurrentServer; TCP=2000"`.
2) Установка TCP-сессии: отправляется запрос подключения на порт, полученный в результате  выполнения предыдущего этапа. Далее отправляется идентификатор сервиса, завершающийся переводом строки. Возможные варианты: `"echo\n"`, `"rand\n"`, `"time\n"`. В результате будет получен один из трех ответов:

	- `"OK\n"`  — при успешном запросе.
		
	- `"ErrorInquiry\n"` — при неудачной попытке поиска сервиса.
	
	- `"ErrorService\n"` — при внутренней ошибке сервиса.
	
3) Обмен данными с использованием протокола TCP: Взаимодействие может происходить с любым из доступных сервисов:
	
	- `Echo` — Клиент отправляет строку `"echo\n"`. Затем отправляет произвольным массив байт, сервер возвращает идентичный массив.

	- `Time` — Клиент отправляет строку `"time\n"`. Сервер возвращает строку с датой и временем в формате `"dd.mm.yyyy/hh.mm.ss"`
	
	- `Rand` — Клиент отправляет строку `"rand\n"`, сервер отвечает случайным числом, представленным бинарным значением типа `int32_t`, размером 4 байта.
